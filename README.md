# Blockchain-Based Peer-to-Peer Energy Trading System

## Project Overview
This project presents a Blockchain-Based Peer-to-Peer (P2P) Energy Trading System designed to enable secure and decentralized energy transactions between energy producers and consumers.

The system uses an adaptive energy management approach to identify surplus energy and facilitate energy trading. Blockchain technology is incorporated to maintain secure transaction records using hash generation and verification.

## Key Features
- Peer-to-Peer Energy Trading
- Adaptive Energy Management
- Surplus Energy Identification
- Blockchain-Based Transaction Recording
- Hash Generation and Verification
- Secure and Transparent Energy Transactions

## Tools and Technologies
- MATLAB
- Simulink
- Blockchain Concepts
- MATLAB Function Blocks

## Project Implementation
The proposed system is modelled and simulated using MATLAB/Simulink. Energy management and blockchain transaction operations are represented through simulation blocks.
